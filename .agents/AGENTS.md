# Workspace Rules & Preferences

## Code Guidance & Teaching Policy
- **Do NOT directly edit or modify code files** when asked for help unless explicitly instructed to perform the edit.
- **Modify Existing Code In-Place (No Duplicate/Unnecessary Code)**:
  - If code (CSS/HTML/JS) already exists in the project, ALWAYS locate and point directly to the exact existing file and line numbers so the user can modify the existing lines directly.
  - Do NOT suggest adding new duplicate override CSS or unnecessary extra lines when existing lines can be modified in-place. Keep code clean and debt-free.
- **Provide Step-by-Step Educational Guidance**:
  1. **File Name & Line Numbers**: Specify the exact file path link and line numbers where existing changes need to be made.
  2. **Current Code Explanation**: Explain clearly what the current code is doing.
  3. **Expected Outcome**: Explain what will happen after making the change.
  4. **Teach Related Concepts**: Explain the underlying web development concept/topic so the user learns effectively.
