### Step 2: Save to Correct Folder
Save the generated image with the **exact same filename** into:
```
c:\Users\91930\Documents\webstart\downloaded_images\
```
For example: save the Hero image as `h1-img.png` in that folder — it will automatically replace the old one.

### Step 3: No Code Changes Needed
Since you're keeping the **same filenames**, the `<img src="...">` and `data-background="..."` attributes in [index.html](file:///c:/Users/91930/Documents/webstart/index.html) will automatically pick up the new images.

### Step 4: Optimise for Web Performance
- Save photographs as `.webp` (70% smaller than JPG).
- Save illustrations with transparency as `.png`.
- Keep images under 300KB each for fast loading.
